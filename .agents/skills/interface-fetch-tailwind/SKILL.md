# Interface et interactions

Lire le README et inspecter les pages et scripts existants. Utiliser HTML, Tailwind CSS et JavaScript simple, sans bibliotheque non demandee. Initialiser les interactions apres DOMContentLoaded ; selectionner les elements de la page et verifier leur existence avant d'ajouter les listeners.

Utiliser fetch pour communiquer avec l'API JSON et preventDefault quand le comportement natif du formulaire doit etre intercepte. Verifier les erreurs HTTP, les reponses invalides et success: false ; les traiter avec try/catch ou catch. Mettre a jour l'interface sans rechargement complet lorsque pertinent et afficher les donnees utilisateur sous forme de texte sur.

Pendant une operation asynchrone, afficher un spinner dans le bouton concerne, desactiver ce bouton et empecher les doubles soumissions. Afficher le resultat et restaurer l'etat dans finally, meme en cas d'erreur. Respecter les pages, champs et fonctionnalites prevus dans le README et verifier les interactions modifiees.
